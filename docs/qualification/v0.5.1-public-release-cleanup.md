### First public CI run and the Rust 1.99 fix

The first `check` run on PR 1 (commit `5ae2f2c`, run
[38124738598](https://github.com/agentcommunity/goal-cup-tracer/actions/runs/38124738598))
failed at clippy: the runner's stable Rust is 1.99.0, which deprecates
`AtomicUsize::fetch_update` ("renamed to `try_update`"), and `-D warnings` makes that an error.
The macOS gate above (1.98.0) and the Linux gate (1.97.0) predate the deprecation. The fix
calls `try_update` (same arguments and result) in
`crates/goalcup-platform/src/handle_budget.rs` and `crates/goalcup-cli/src/proxy/mod.rs`, and
raises `rust-version` to `1.99` (owner decision). No runtime behaviour changes.
