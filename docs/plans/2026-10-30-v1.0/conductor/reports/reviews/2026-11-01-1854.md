## 6 Risks

1. **Point 3, recorder start (high, new).** The control-line overflow (state item 3) stops recording on every boot for a
   participant with a large `.env`, and the harness's proxy then points at nothing. More generally, anything the watchdog
   sends at boot must be bounded before it is sent.
2. **Point 4, a silent pass in the rig (high, new).** Section 3 item 4. Until `check.py` fails a plain hit, no row on the new
   head is evidence for exact-value masking.
3. **Point 4, Hermes's search index (high).** No byte rule can mask a no-shape value that Hermes cuts from its context, or a
   term stored without its first bytes. The owner's keep decision rests on "covered". The same class applies to OpenCode's
   and OpenClaw's SQLite copies, which the participant text does not mention.
4. **Point 4, value order and the cut (medium, new).** The order is `GH_TOKEN`, then environment values, then `.env*` values,
   with 32 used. A developer shell with many credential-named variables pushes the `.env` values out, and those are the ones a
   harness prints with `cat .env`. The skipped count is shown, but only on the start screen.
5. **Over-masking (low to medium).** The name gate's words match `PASSPORT`, `COMPASS` and `MONKEY`. A `*_KEY` variable holding
   a model id of 20 or more bytes would star every model name in the record and break PRD-09's usage reader. Add one negative
   test with a model-id value.
6. **`goalcup recover` from a different shell (low).** Source 2 is rebuilt from the recover shell's environment, while the
   harness keeps its original one. Values present only in the first shell go unmasked after a recover. Say so in the recover
   text, or carry the values in the watchdog's run file (memory only today).
7. **Point 2 at scale (high, unchanged).** No row has had more than 5 subagents; A2 needs 15 and A1 needs 20. Both wait on the
   cap raise.
8. **Gateway, point 7 (high, unchanged).** 0 rows; A3 and A4 blocked.
