## Checked and aligned

- **F1:** one stream per WebSocket direction with end-of-message flag; raw bytes, no base64, no number arrays; light binary framing; GAP with start and end; written counts; off spans (`recorder_down`). Aligned.
- **F2:** level 3, window 2^27, long matching, written at record time; `zstd -d` default limit 2^27 is right. Aligned except P01-1.
- **R4, R5:** every loss is a GAP with reason and `lost` (bytes plus one); no caps of our own (the 16 MiB reader bound, 256 KiB pieces and 512 MiB rotation are not caps on recording); memory guard names listed. Aligned except P01-8.
- **R6:** COUNT covers only records already written; counts that leave the machine are at the durable LINK; "model requests written" is a request count, not a call count. Aligned except P01-3, P01-17.

- **R3, R7:** `recorder_down` and `prev_boot` mark each restart; null mode is off time; sleep is not. Aligned except P01-2, P01-4, P01-5.
- **H3, H5, H6, H8:** tunnels recorded with host, bytes, times; listed-host tunnels get a named GAP (6, 7, 11, 13, 14); HTTP/2 meta (`h2`, pseudo-headers, `h2_error`); session-file path is the ID across boots and entries. Aligned.
