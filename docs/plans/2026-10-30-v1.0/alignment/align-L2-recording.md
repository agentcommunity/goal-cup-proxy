## What was checked and found aligned

- **R1.** PRD-03 rule 2 records every byte on a decrypted connection, no path, Host or method filter;
  WebSocket control frames are now recorded; tunnels are records at open with no row cap. PRD-04 `**`
  patterns, no row, slot or file cap, every row from the run start. Unlisted hosts are tunnels by H3.
- **R2.** PRD-02 section 7 (relay only offers, no backpressure on the wire, recording at low priority);
  PRD-03 rule 1 (relay first), rule 7 (wait, never refuse, on descriptors); PRD-06 two plain threads
  off the relay runtime. Exceptions noted in L2-07 and L2-14.
- **R3.** Same port held by the watchdog, restart pauses 0 to 5 s with no cap, `recorder_down` gap
  from the last LINK with `cause`, `prev_boot` event, same CA across boots (PRD-03 section 10), kill
  test with each gap under 2 s (PRD-02 R1, PRD-01 acceptance 3), first boot failure refuses the
  launch, `continue` reuses the port. Gaps: L2-03, L2-05, L2-06, L2-13.
- **R4.** Every GAP has start and end fields and an extent (PRD-01 invariant 12); the `conn` GAP for
  a connection that stops parsing (PRD-03 5a); listed-host tunnels get a GAP; native `source_changed`
  with `unread_at_least`; `cut_at_seal` with exact bytes; verifier invariants 4, 10, 11 and 14 check
  holes. Gaps: L2-01, L2-02, L2-10, L2-11, L2-12, L2-16.
- **R5.** No caps on connections, streams, subagents, files, rows, bytes, run size (PRD-02 7 rule 4,
  PRD-03 11, PRD-04, PRD-06, PRD-07 section 5 deletes the 413). The 32 MiB chunk cap and 2 KiB
  `counts` limit stop no recording. Notes: L2-07, L2-15, L2-18.
- **R6.** Counted at write by the writer only (PRD-02 6); heartbeat and server counts at the durable
  LINK (PRD-01 9, PRD-06 6, PRD-07 4, server keeps the highest); `off_ms` and `off_spans` in the
  heartbeat; status and end screen show written counts, holes and off time (PRD-10 4 and 5); never
  called "calls". Gaps: L2-04, L2-17.
- **R7.** `failed` means null mode, a state not a latch, sent at once on a state change (PRD-06 6,
  PRD-07 4); status says "The server is told" (PRD-10 4). Gaps: L2-03, L2-05, L2-08, L2-13.
- **R8.** The recorder parses only framing needed to relay, decode and mask; PRD-04 never parses
  file content; no subagent hints added (PRD-01 5); usage after upload (PRD-09). The writer reads only
  `host` and `mode` from `conn` OPEN meta for written counts.
