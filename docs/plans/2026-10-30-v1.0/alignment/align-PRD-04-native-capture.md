## Checked and found aligned

- Ledger L5 (one process): native reader is a thread with S1 calls only; producers, epochs, admission,
  latch and the handle budget are cut (sections 1, 5, What is cut).
- R5 no file, stream, row or depth cap; the 64 MiB slice is fairness only; the 2% duty cycle limits
  latency, never bytes (sections 2, 3, 5).
- R2 and point 3: low priority thread, no descriptor held between passes, `O_NONBLOCK` so a FIFO cannot
  hang, reads bounded by `room()`, never parses.
- R8 and the hard rule "record raw": no SQLite dependency, no line parsing, no hints (sections 4, 6).
- M1 and point 4: every byte passes PRD-05's masker before disk; length-preserving masks; no symlink
  followed at any level; the reader never writes, locks or renames.
- AGENTS.md "never write into `~/.claude` ...": nothing is written by the reader.
- H7, H8 and point 7: rows are data from PRD-11; one walk for every harness; the path is the ID.
- R3 and kill test: resume from durable cursors, overlap allowed, hole forbidden (PRD-01 invariant 14,
  PRD-02 9.3).
- PRD-00 S1, S3, S8 shapes and the "Smaller interface rulings" row PRD-02/PRD-04 match section 1.
- PRD-00 "Not in this build": hot and quiet scheduler, tail witness and 20,000-file soak script are cut.
