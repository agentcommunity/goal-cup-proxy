# One capture system: decision ledger

Running log of choices made while building the [plan](2026-10-28-one-capture-system.md) against the
[spec](2026-10-28-one-capture-system-spec.md). The owner gave the builders room to change the plan
when the product ends up better; every such change is written here with its reason. Newest last.

| # | Date | Decision | Why |
|---|---|---|---|
| L1 | 28 Oct | One branch and one worktree per PR, all cut from `main`: `capture/t1-native-optional`, `capture/t5-evidence-label`, `capture/t67-tunnel-list`, `capture/t234-model-host-defaults`, `capture/t8-docs-d74`. | Parallel builders without shared state; each PR reviews on its own. |
| L2 | 28 Oct | The spec, plan and this ledger land on `main` first, through the Vercel Gateway results PR. | Every later PR links to them; the docs PR's link check passes. |
| L3 | 28 Oct | Builders run focused tests on the cloud container; `sh scripts/gate.sh fast` runs once per PR on a Vercel Sandbox gate machine forked from one snapshot. | The container has 4 cores; GitHub runners are slow; the sandbox has 8 and a non-root user. |
| L4 | 28 Oct | Subscription-login runs (Claude Code, Codex ChatGPT) wait for the owner's laptop; the agents prepare a test guide and run every gateway-key path in the sandbox. | Subscription logins on a datacenter IP risk the account (account-safety research, 28 Oct). |
| L5 | 28 Oct | Wall times in `wire_request_range` compare as times (seconds, then fraction), using the one `Rfc3339Utc::chronological_cmp`, now `pub`. | As text, `12:00:00.5Z` sorts before `12:00:00Z`. |
| L6 | 28 Oct | `wire_request_range` sits inside `analysis.cross_leg` (plan), although the spec said `cross_leg` is unchanged; only its state rule is unchanged. | One place for the wire-versus-native facts. |
| L7 | 28 Oct | `evidence` counts native *model activity*, not native lines: a session file with no model work labels `none`. | A file of `unknown` lines is no evidence of model work. |
| L8 | 28 Oct | `goalcup-verify --research-json` stderr line gains `evidence <label>`. | One glance shows the label; no script parses the line (`scripts/matrix.sh` only logs it). |
| L9 | 28 Oct | `absent` uses the schema's `closed_enum!` macro, not a serde derive. | A bad value gets the standard schema 1 message naming the field. |
| L10 | 28 Oct | A `via` value that is not a plain name is refused without echoing it. Empty or whitespace-only values count as missing. | "Nothing else of the file is said" (D62); an empty string names no host. |
| L11 | 28 Oct | A config gateway opens beside the connector's default host rows, not instead of them. | Records more, never less; a participant who switches back mid-run stays recorded. Cost: the default host is still probed at start. |
| L12 | 28 Oct | Hermes keeps `auth_hosts` as on `main` (plan said add three refresh hosts). | Unapproved hosts are tunnelled anyway; the setup TCP probe of every sign-in host would fail setup on networks that block x.ai or OpenAI. |
| L13 | 28 Oct | Under `absent = "defaults"` only a missing file, key, `via` value or table falls back. A file that exists but is a symlink, unparseable, too big or unreadable is refused at start. | A participant learns at start instead of silently tunnelling the gateway. |
| L14 | 28 Oct | Codex `[profiles.*] model_provider` is not followed; the recipe says set `model_provider` at top level. A profile-selected gateway tunnels and shows in the sealed-hosts list. | One indirection only (spec R2). |
| L15 | 28 Oct | Removing the `env` deny word also relaxes `participant.no_prompts` and `time_left_tool` keys, which share the check. | One rule for config keys; a key never holds a secret value it reads. |
| L16 | 28 Oct | Zero native rows also fixed `check_cross_field`, which indexed `native[0]` and would have panicked; a frozen fixture `schema1-wire-only` runs the zero-row path through the dynamic connector contract. | The plan named only `check_native`; the fixture is the only end-to-end run of a wire-only connector. |
| L17 | 28 Oct | Sandbox runs use free gateway models (`nvidia/nemotron-3.5-lightning-free`, `poolside/laguna-s-2.1-free`), not `deepseek/deepseek-v4.1-flash`. | The gateway answers 403 "Free tier users do not have access to this model": the team has no paid credits. |
| L18 | 28 Oct | Gate machine fixes kept in the snapshot, not the repo: `setpriv` drops the ambient capabilities `sandbox exec` gives uid 1000; `libnss-myhostname` resolves `*.localhost` because `/etc/hosts` is read-only; GNU coreutils replace uutils. | Each made correct tests fail on the sandbox only. |
| L19 | 28 Oct | A test fix PR lands first: `a_failed_after_exit_command_does_not_wait_on_a_held_proxy_connection` fails on Linux on `main` since f7b7605. | The gate on `main` fails 1 of 2193 tests; CI's `check` is a smoke and missed it. |
| L20 | 28 Oct | E1 measured: Codex 0.165.0 reads the key from `$CODEX_HOME/.env` under `env -i` and posts to `/codex/v1/responses` over plain HTTPS (no WebSocket). E2 measured: Claude Code 2.1.312 takes the gateway from `settings.json` `env` alone. | Confirms the Codex and Claude recipes before the code runs. |
| L21 | 28 Oct | The sealed goal sentence `CHAT_MODE_GOAL` ("recorded in the harness's session files") stays unchanged for now, though a wire-only run has no session file. | It is sealed into every chain; Hermes already had the same gap. Owner to decide the wording before a wire-only connector ships. |
| L22 | 28 Oct | A connector with zero native rows needs a binary with this change; older binaries refuse it with their own message. Pinned connectors ship with their binary, so this bites only `--dev`. | Widening a bound is additive for new binaries, not old ones. |
| L23 | 28 Oct | Model-host refusals name the file path and the setting, with a remedy (copy instead of link, plain JSON without comments, size). The fallback logs a `model service:` line too. Deny words gain `apikey` and `password`; a `*` may not be the last key part; an empty file counts as missing. | Review: a participant could not act on "choose such a service there"; `env.*` names would otherwise pass the deny check. |
| L24 | 28 Oct | The fallback trusts the absence of one key: a Codex profile, a built-in local provider (`ollama`) or Claude's Bedrock switch records only the default hosts. | Documented, not built: a profile provider or Bedrock tunnels and shows in the sealed-hosts list; `ollama` on this computer is not seen at all (`NO_PROXY` covers loopback); either way the run labels `native_only`. |
| L25 | 28 Oct | The tunnel list is stored once per entry at `traces/<event>/<run>/<entry>/tunnels.jsonl` (create-only, first wins), bounded to 8 MiB, with the same 502-and-retry rule as seal and baseline. Plan said `tunnels-<sha>.jsonl`, 16 MiB, and the first build logged a failed put and answered 200. | Review: a repeat seal with a new list each time grew R2 without bound; a 48 MiB body cap risked the Worker's 128 MB. A real list is at most about 4 MB. |
| L26 | 28 Oct | A tunnel cut open at the stop is noted too (bytes `null`); a tunnel still open when finish cannot reap its task gets no note. The local file is `tunnels-<entry_id>.jsonl`, one per entry, so `continue` never overwrites a list. | Spec R3 "completed or cut"; the spec's `tunnels.jsonl` name predates per-entry files. |
| L27 | 28 Oct | Measured on the integrated build (sandbox, free model): Codex through the gateway `wire_and_native` (17 requests), Hermes `wire_only` (9), the `http://localhost:4000` refusal names `settings.json`; the gateway is in no sealed-hosts line. Claude Code recorded 19 calls but labelled `wire_undecoded`: the Anthropic decoder accepted only the exact path `/v1/messages`, not `/claude-code/v1/messages`. The rerun with the decoder fix (#286) labelled `wire_and_native` (15 requests). | The plan's measured runs are the proof; a unit test of the reader alone would have missed the decoder. |
| L28 | 28 Oct | A second intermittent daemon test (`capture_lifecycle` seal with a lost registry write) and the `harness_build` exec race are root-caused and fixed in their own PRs before the last merges. | "Flake" is not a root cause; the gate must pass on every PR. |
| L29 | 28 Oct | The Anthropic decoder accepts any hinted path ending in `/messages` (decoder version 3 to 4); `/messages/count_tokens` and `/messages/batches` stay unsupported. The private research report now names the gateway base path in `endpoint`. | Only streams the CLI hinted `anthropic-messages` reach it, and every hinted path ends in `/messages`; a tighter `<prefix>/v1/messages` would reject the `<base>/messages` hint. |
