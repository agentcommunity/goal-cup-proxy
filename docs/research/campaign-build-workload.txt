Build a small static website generator in Python in this repository, using only the standard library, and push your work to it. Work on your own: nobody will answer questions or approve anything, so decide everything yourself. Start with a short plan in PLAN.md and a GOALCUP.md that says what the project is, how to run it and its current status; keep GOALCUP.md up to date as you go. Build it in small steps: 1 turn a folder of Markdown files into HTML pages; 2 a page template with a title and navigation; 3 an index page that lists every page; 4 tags and one page per tag; 5 a watch command that rebuilds on change; 6 a link checker for the generated site; 7 a README with examples; 8 keep improving tests and error messages. After each step run the tests with python3 -m unittest, fix what fails, commit, and git push to origin. Use your harness's subagent or task tool at least twice: once to have a subagent write the tests for a step while you write the code, and once to have a subagent review your code and report bugs, which you then fix. Now and then run goalcup time-left in your shell to see how much time is left, and plan around it. Stay inside this workspace. Do not read files outside it, do not read any login, key or credential file, and do not install anything. Keep each answer short. When you run out of useful work or have less than 10 minutes left, push your final work and stop.
