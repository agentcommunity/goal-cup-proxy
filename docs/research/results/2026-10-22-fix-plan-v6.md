# Fix plan v6, local test day 2026-10-22 (Goal Cup's home lock collides with Claude Code's)

After [v5](2026-10-22-fix-plan-v5.md). In round 2 (22 Oct ~02:00Z) both Claude Code cells (Mac
2.1.299, Docker 2.1.283) stalled about a minute after start: "Could not refresh your login because
another Claude Code process is refreshing it (or exited mid-refresh)". Their logins were ~8 h old,
so the first request needed an OAuth refresh.

## Cause (measured)

- Claude Code serialises a token refresh with proper-lockfile on `realpath(CLAUDE_CONFIG_DIR) +
  ".lock"` (stale 60 s): `mkdir`; on EEXIST with an mtime under 60 s it is ELOCKED; after retries it
  gives up and, with an expired token, shows that error and stops.
- Goal Cup's shared-home lock is the regular file `<capture-homes>/<connector>.lock`
  (`crates/goalcup-cli/src/home.rs` ~106), held for the run; `note_home_holder` (~147) rewrites it at
  start and continue, so its mtime is fresh: for claude-code-cli it is exactly Claude's lock path.
- Effect: any start or `continue` whose Claude token has already expired stalls at the first
  request (common: sign in at prep, start hours later; continue after a night). Later refreshes
  succeed (the file is older than 60 s by then). Hermes (`auth.lock` inside its home) and Amp (home
  `amp-cli.run-home`) do not collide; Codex not fully ruled out.

## Item R1 (product)
- Goal Cup's lock becomes `<capture-homes>/<connector>.goalcup.lock` (a name no harness uses).
- Upgrade safety: while taking it, also try-lock an existing old `<connector>.lock` without creating,
  writing or holding it, and refuse if it is busy (a run on the old binary still holds it). Remove
  that check in a later release.
- Update the tests that build the old name (`tests/it/prep.rs` ~1483, 1486) and any docs naming it.
- Test: after `lock_shared_home` + `note_home_holder`, `create_dir("<home>.lock")` (what
  proper-lockfile does) succeeds, and a second `lock_shared_home` is still refused; an old-name lock
  held by another process makes the new lock refuse.

## Done when
`sh scripts/gate.sh fast` passes; a Claude Code cell whose token has expired starts working without
anyone typing.
