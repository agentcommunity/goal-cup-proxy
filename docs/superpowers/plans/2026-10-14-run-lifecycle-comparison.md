## Rotating parts: checked against the code

No severe blocker. What it costs: records never carry a byte offset (`Envelope::chain_bytes` is the hashed bytes, `export.rs:17`), so a part boundary changes nothing in the chain. The uploader keeps one logical offset (part start = sum of earlier parts), so the server stores one stream and its verify is unchanged. The work: `tracecap` gains `open_part`/`list_parts` under the D40 open rules (two `open_append` call sites today); `TraceExport` rotates after `sync_capture` (the durable frontier); resume validates the surviving parts in order and starts mid-chain from the first record's `link.prev`/`seq` when part 0 is gone; `build_chunk` never crosses a part; the verifier reads parts in order (one `open_file(CHAIN_FILE)` today, `reader.rs:217`); `key_scan` checks the last part. "One part = one chunk" holds only roughly: chunks are capped at 32 MiB compressed (`uploader.rs:37`), so a 256 MiB part is one or two chunks. A crash with a torn tail in the last part stays a failed reopen, and `continue` closes it from `local_end`.

## Open risks the owner should know

1. Reading parts mid-chain needs a "phase already open" start for `ChainPhaseReplay`; if that check is wrong, a reopened segment refuses valid records. T3/R2 tests pin it, but it is the one subtle protocol change.
2. APFS local snapshots (Time Machine) keep deleted parts' blocks until macOS purges them, so `statvfs` free space can lag. The reserve file covers our own bytes, not that lag.
3. `codex resume --last` and `claude --continue` in the tracer's shared home, and when interactive Codex creates its session file, are unmeasured. T6 measures them before any connector is merged.
4. With no terminal host, a closed window or a reboot stops the agent until the participant runs `goalcup continue`. The 20-minute email is the only prompt, so a participant asleep for 8 hours loses 8 hours of agent time (not data).
5. `MAX_CONNECTION_FAILURES = 10` per launch (`proxy/ingest.rs:98`) is never reset: a week of daemon stalls can switch the wire leg off for good. The status line and the heartbeat make it loud, but it is not fixed here.
